智慧藥盒硬體模擬器（不需要 ESP32、不需要 COM 埠）

用途
1. 模擬左到右「早／中／晚」三格藥盒開啟與關閉。
2. 直接連接原本 Django API，事件會寫入同一個資料庫。
3. 可測試提醒配對、服藥紀錄、裝置在線狀態與 Agent。
4. 會顯示 Django 原本要傳給實體藍／紅／綠 LED 和蜂鳴器的狀態。
5. 不會讓實體 LED 或蜂鳴器動作。

使用方法
1. 先用原本方式啟動 Django，確認 http://127.0.0.1:8000/dashboard/ 可以開啟。
2. 雙擊本資料夾內的 START_HARDWARE_SIMULATOR.bat。
3. 保持黑色模擬器視窗開啟；它每 30 秒會送出心跳，網站會顯示裝置在線。
4. 在模擬器按鍵：
   1/2/3 = 早／中／晚開盒
   4/5/6 = 早／中／晚關盒
   P/C   = PIR 有人／無人
   S     = 查看預期 LED 與蜂鳴器狀態
   Q     = 離開
5. 回到瀏覽器重新整理儀表板，即可看到事件。
