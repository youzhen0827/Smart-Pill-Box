請用 Android Studio 開啟這個資料夾：v2.1_Android_8_ai_esp32_usb

這是已訓練 MiniCPM5-2B＋ESP32 USB 第 8 版；語音問藥仍可由 APP 獨立查詢。
App 標題會顯示：💊 智慧藥盒管家
感測器測試 Spinner 只會有：早、中、晚。

模型安裝：
  1. 安裝並開啟一次 APP
  2. 用 USB 連接手機
  3. powershell -ExecutionPolicy Bypass -File .\install_trained_model.ps1

模擬器連 Django：
  http://10.0.2.2:8000/api/v1/
Token：
  smartpill-dev-token

「測試連線」會驗證 Django health API 是否為三格、ui_revision=8、USB 硬體傳輸，並顯示 MiniCPM5-2B Agent 與藥盒在線狀態。
