# 修改摘要：Android 流程化介面 v6

- 新增 AI Agent 追蹤分頁，只顯示等待開盒、再次提醒與需要確認的任務。
- 語音衛教加入常見問題選單，回答依用途、副作用、服用方法、交互作用與警告分流。
- 啟動時自動檢查 Django，並要求後端 `ui_revision=6`。
- 使用五種參考色分開配置頁籤、統計與狀態，不使用漸層。

- 首頁只有 3 格：早、中、晚。
- 新增提醒、固定排程、感測器測試只允許 slot 1～3。
- API 列表只顯示合法三格資料；舊偏好值 4～7 會被收斂到 1～3。
- 固定排程同時送出 period，與早/中/晚 slot 完全對齊。
- 「測試連線」會核對 Django health contract，舊七格後端會顯示版本不符。
- 專案名稱更新為 `v2.1_Android_6_workflow`。
